# Соответствие 152-ФЗ (персональные данные пациентов)

Emkaro реализует технические меры защиты персональных данных (ПДн) в медицинской информационной системе.

## Реализованные меры

| Мера | Реализация |
|------|------------|
| Аутентификация | HTTP-only cookie, HMAC-подпись сессии (`AUTH_SECRET`) |
| Разграничение доступа | RBAC по ролям + модули клиники (супер-админ) |
| CSRF | Проверка Origin/Referer на изменяющих запросах |
| Rate limit входа | Блокировка после серии неудачных попыток (in-memory, одна реплика app) |
| Шифрование ПДн | AES-256-GCM для ФИО, SNILS, паспорта, телефона, email, адреса, заметок, диагноза (`PHI_ENCRYPTION_KEY`, обязателен в production) |
| Журнал доступа | Таблица `audit_logs`, API `/api/audit`, просмотр карточки пациента |
| Согласия | Таблица `patient_consents`, API `/api/patients/[id]/consents` |
| Экспорт / обезличивание | API `/api/compliance` (действия `export`, `anonymize`) |
| Security headers | `next.config.ts` (CSP, HSTS, X-Frame-Options и др.) |

## Переменные окружения (production)

```env
AUTH_SECRET=<случайная строка ≥32 символов>
PHI_ENCRYPTION_KEY=<случайная строка ≥32 символов>
TLS_ASK_SECRET=<случайная строка ≥32 символов>
DATABASE_URL=postgresql://...
ENABLE_DEMO_ACCOUNTS=false
```

**Важно:** после включения `PHI_ENCRYPTION_KEY` не меняйте ключ без миграции — иначе зашифрованные поля не расшифруются.

## Инициализация БД

```bash
docker compose exec app node scripts/init-db.mjs
```

Применяет `schema.sql` и `db/migrations/*.sql` (в т.ч. `audit_logs`, `patient_consents`).

## Операционные процедуры

1. **Регулярные бэкапы** — `scripts/backup-db.sh` (см. `docs/DEPLOY.md`).
2. **Журнал доступа** — владелец/админ: Настройки → блок «152-ФЗ».
3. **Запрос субъекта ПДн** — экспорт JSON или обезличивание в том же блоке.
4. **Согласия** — фиксируются через API (UI в карточке пациента — расширяемо).

## Организационные меры (вне кода)

Для полного соответствия 152-ФЗ оператору (клинике) необходимо:

- Политика обработки ПДн и согласия пациентов (бумажные/электронные)
- Приказ о назначении ответственного за ПДн
- Договоры с обработчиками (хостинг, если применимо)
- Реестр обработки ПДн

ПО обеспечивает техническую часть; юридическое оформление — на стороне клиники.
