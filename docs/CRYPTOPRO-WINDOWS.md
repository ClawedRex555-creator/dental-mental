# КриптоПро на втором ПК (агент подписи для Emkaro)

Emkaro на сервере (Linux/Docker) **не видит** USB-флешку с КЭП. Подпись делается на **Windows-ПК с КриптоПро**, через небольшой **агент подписи**.

```
Сервер Emkaro  --VPN/LAN-->  Windows ПК + флешка КЭП  --cryptcp-->  откреплённые подписи
```

---

## Шаг 1. Отпечатки сертификатов (на Windows)

1. Вставьте флешку врача → **КриптоПро CSP** → **Сервис** → **Просмотреть сертификаты в контейнере**
2. Сертификат → **Свойства** → **Состав** → **Отпечаток** (40 hex, без пробелов)
3. Повторите для **КЭП организации** (вторая флешка или другой контейнер)

Куда в Emkaro:

| КЭП | Куда |
|-----|------|
| Врач | **Сотрудники → врач → ЕГИСЗ / N3 → Отпечаток КЭП врача** |
| Организация | **Настройки → N3 / ЕГИСЗ → Отпечаток КЭП организации** |

---

## Шаг 2. Агент на Windows

На ПК с КриптоПро (нужен [Node.js](https://nodejs.org/) LTS):

```bat
cd C:\emkaro-signing
REM Скопируйте сюда папку scripts/egisz-signing-agent из проекта

set EGISZ_SIGNING_SECRET=сгенерируйте-длинный-секрет
set EGISZ_SIGNING_PORT=9876
set CRYPTOPRO_CRYPTCP=C:\Program Files\Crypto Pro\CSP\cryptcp.exe

node server.mjs
```

Или двойной клик по `start-windows.bat` (после `set EGISZ_SIGNING_SECRET=...` в cmd).

Проверка на этом же ПК:

```bat
curl http://127.0.0.1:9876/health
```

Должно: `{"ok":true,"cryptcp":"..."}`

**Важно:** во время подписи вставлены **обе** флешки (врач + МО) или по очереди переставляйте — агент подписывает сначала врачом, потом организацией.

---

## Шаг 3. Сеть: сервер → Windows

Сервер `201.51.0.171` должен достучаться до Windows по IP и порту **9876**.

Варианты:

- Windows в той же сети, что клиника + **проброс порта** / VPN на сервер
- **WireGuard / OpenVPN** между сервером и ПК (как уже сделано для N3)
- Временно: тест с `curl` с сервера на внешний IP роутера с пробросом 9876

На сервере проверка:

```bash
curl -s http://IP_WINDOWS_ПК:9876/health
```

---

## Шаг 4. Emkaro на сервере

В `/opt/emkaro/.env` добавьте (тот же секрет, что на Windows):

```env
EGISZ_SIGNING_URL=http://IP_WINDOWS_ПК:9876/sign
EGISZ_SIGNING_SECRET=тот-же-секрет
```

Перезапуск:

```bash
cd /opt/emkaro
docker compose up -d app
```

В **Настройки → N3 / ЕГИСЗ** клиники:

- Подключение: **Live**
- Подпись: **CryptoPro**
- Отпечаток КЭП организации — заполнен
- У врача в карточке — отпечаток и СНИЛС, OID ФРМР

---

## Шаг 5. Тест подписи с сервера

```bash
curl -s -X POST "$EGISZ_SIGNING_URL" \
  -H "Authorization: Bearer ВАШ_СЕКРЕТ" \
  -H "Content-Type: application/json" \
  -d '{"xml":"<?xml version=\"1.0\"?><test/>","doctorCertThumbprint":"ОТПЕЧАТОК_ВРАЧА","orgCertThumbprint":"ОТПЕЧАТОК_МО"}'
```

Успех: `"ok":true` и три поля base64.

---

## Частые ошибки

| Симптом | Решение |
|---------|---------|
| `cryptcp exit 1` | Флешка не вставлена, неверный отпечаток, истёк сертификат |
| Сервер не достучивается | Firewall Windows → разрешить входящий TCP 9876 |
| `Unauthorized` | Секрет в `.env` ≠ секрет на Windows |
| N3 AddMedRecord Fail | Проверьте Live + CryptoPro + VPN N3 на сервере |

---

## Автозапуск агента (опционально)

Планировщик заданий Windows: при входе пользователя запускать `start-windows.bat`, ПК не усыплять, флешки всегда в USB-хабе на рабочем месте.
