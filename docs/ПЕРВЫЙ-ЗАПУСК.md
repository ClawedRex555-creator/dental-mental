# Первый запуск на сервере (для новичков)

Завтра можно начать тесты **без покупки домена** — по адресу `http://IP-вашего-сервера:3000`.

---

## Что такое домен (за 30 секунд)

**Домен** — это имя сайта вместо цифр.

| Без домена | С доменом |
|------------|-----------|
| `http://185.123.45.67:3000` | `https://ulybka.emkaro.ru` |

Домен **emkaro.ru** можно подключить после тестов по IP — см. [EMKARO-RU.md](./EMKARO-RU.md).  
**Timeweb пошагово:** [TIMEWEB-СТАРТ.md](./TIMEWEB-СТАРТ.md)

---

## Что нужно сегодня (2 покупки)

### 1. VPS — «компьютер в интернете»

Это сервер, на котором крутится программа 24/7.

**Где взять (Россия, простые панели):**

| Сервис | Что заказать | Цена ориентир |
|--------|--------------|---------------|
| [Timeweb Cloud](https://timeweb.cloud) | Cloud Server, Ubuntu 22.04, 2 GB RAM | ~400–800 ₽/мес |
| [Selectel](https://selectel.ru) | VPS, Ubuntu | ~500 ₽/мес |
| [Reg.ru](https://www.reg.ru) | VPS | ~300–600 ₽/мес |

**Минимум:** 2 GB RAM, 20 GB диск, **Ubuntu 22.04 или 24.04**.

После оплаты в письме/панели будут:

- **IP** — например `185.123.45.67`
- **Логин** — обычно `root`
- **Пароль** — для входа по SSH

### 2. Открыть порт 3000

В панели VPS найдите **Firewall / Сеть / Группы безопасности** и разрешите:

- **TCP порт 3000** — для доступа к МИС
- **TCP порт 22** — для SSH (обычно уже открыт)

Без этого браузер не откроет сайт.

## Шаг 1: Загрузить проект на сервер

### Вариант А — архив с вашего ПК (проще всего)

1. На Windows создайте архив (без `node_modules`):
   ```powershell
   cd "путь\к\проекту"
   powershell -ExecutionPolicy Bypass -File scripts\pack-for-server.ps1
   ```
   Получится **`emkaro-deploy.zip`**.
2. Скачайте [WinSCP](https://winscp.net/) или используйте терминал.
3. Подключитесь к серверу:
   - Хост: IP сервера
   - Пользователь: `root`
   - Пароль: из письма хостинга
4. Загрузите zip в `/opt/` и распакуйте:

```bash
# На сервере (через SSH — PuTTY или «Терминал» в панели хостинга)
cd /opt
apt install -y unzip
unzip -o emkaro-deploy.zip -d emkaro
cd emkaro
```

### Вариант Б — Git (если проект на GitHub)

```bash
cd /opt
git clone https://github.com/ВАШ-РЕПО/emkaro.git
cd emkaro
```

## Шаг 2: Одна команда — установка

```bash
cd /opt/emkaro
chmod +x scripts/quick-deploy.sh
sudo bash scripts/quick-deploy.sh
```

Скрипт сам:

- поставит Docker (если нет);
- создаст `.env` с паролями;
- запустит базу и приложение;
- создаст тестовую клинику **demo**.

В конце покажет адрес и логин.

---

## Шаг 3: Зайти и проверить

Откройте в браузере (с любого компьютера):

```text
http://ВАШ_IP:3000/login
```

Пример: `http://185.123.45.67:3000/login`

| Поле | Значение |
|------|----------|
| Email | `admin@demo.ru` |
| Пароль | `DemoTest123!` |

После входа — расписание, пациенты и т.д.

**Эту ссылку можно отправить тестировщикам.**

---

## Шаг 4: Сменить пароль (рекомендуется)

Создайте своего владельца и удалите демо-пароль из переписки:

```bash
cd /opt/emkaro
docker compose -f docker-compose.quick.yml exec app node scripts/create-clinic.mjs \
  --slug demo \
  --name "Моя клиника" \
  --email owner@myclinic.ru \
  --password 'ВашНадёжныйПароль123' \
  --owner-name "Владелец"
```

Если клиника `demo` уже есть — создайте другой slug:

```bash
--slug test --name "Тест" --email admin@test.ru ...
```

Тогда в `.env` поменяйте `DEFAULT_CLINIC_SLUG=test` и перезапустите:

```bash
docker compose -f docker-compose.quick.yml up -d
```

## Полезные команды

```bash
# Смотреть логи
docker compose -f docker-compose.quick.yml logs -f app

# Перезапуск
docker compose -f docker-compose.quick.yml restart app

# Остановить
docker compose -f docker-compose.quick.yml down

# Снова запустить
docker compose -f docker-compose.quick.yml up -d
```

## Частые проблемы

| Симптом | Решение |
|---------|---------|
| Сайт не открывается | Порт **3000** открыт в firewall? IP верный? |
| «Клиника не найдена» | Запустите `create-clinic` ещё раз (шаг 2 скрипта) |
| Долго грузится первый раз | Подождите 2–3 мин после `up -d --build` |
| Забыли пароль | Создайте нового пользователя через `create-clinic` с новым email |

## Завтра на тестах — помните

- Данные пациентов пока хранятся **в браузере каждого тестировщика**, не на сервере.
- Для тестов используйте **выдуманных** пациентов, не реальные СНИЛС.
- У каждого тестировщика своя «копия» данных, если заходят с разных ПК — это нормально до следующего этапа.

## Позже: купить домен и поддомены

Когда тесты пройдут:

1. Купить домен на Reg.ru / Timeweb (~300 ₽/год).
2. В DNS: `@` и `*` → IP сервера.
3. Перейти на полный стек: `docker compose up -d` (с Caddy и HTTPS).
4. Создавать клиники: `ulybka.ваш-домен.ru`, `zubki.ваш-домен.ru`.

Подробно: [DEPLOY.md](./DEPLOY.md)
