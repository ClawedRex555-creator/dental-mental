# Справочники НСИ N3 (b2b-demo)

Справочники ЕГИСЗ на тестовом контуре N3 (`b2b-demo.n3health.ru`) **недоступны из обычного интернета** — только через **OpenVPN N3**.

Пример из ответа поддержки:

| Поле | Значение |
|------|----------|
| СЭМД / `remd_code` | **119** — Протокол консультации (CDA) Редакция 4 |
| `IdMedDocumentType` (справочник `1.2.643.2.69.1.1.1.195`) | **198** |

В `AddMedRecord` передаётся **198**, не 119.

---

## Где VPN должен быть

| Место | OpenVPN N3 |
|-------|------------|
| **Сервер** `201.51.0.171` | **Да** — `emkaro-n3-vpn` / `bash scripts/n3-vpn.sh start` |
| **Mac / Windows клиники** | **Нет** — тот же `.ovpn` = вторая сессия, на сервере `AUTH_FAILED` |

Подпись ЕГИСЗ с Windows идёт через **SSH-туннель**, не через OpenVPN на ПК.

---

## С Mac: открыть справочник в браузере (без своего VPN)

```bash
cd /path/to/dentalcloud-mis
bash scripts/nsi-browser-tunnel.sh
```

В другом окне браузера:

```
https://127.0.0.1:18443/nsiui/Dictionary/1.2.643.2.69.1.1.1.195
```

Сертификат N3 самоподписанный — в Chrome/Safari «Дополнительно → перейти на сайт».

Другой OID:

```bash
bash scripts/nsi-browser-tunnel.sh root@201.51.0.171 1.2.643.5.1.13.13.99.2.197
```

---

## Скачать полный справочник (экспорт)

1. Туннель выше **или** VPN только на сервере.
2. Откройте сервис экспорта (нужен **логин НСИ** из ЛК N3):

   `https://127.0.0.1:18443/nsiimportexport`

3. Экспортируйте справочник в JSON/XML.
4. Положите файл в репозиторий:

   `data/nsi/<oid-точки-заменены-на-_>.json`

Автоматический `curl` без авторизации **не работает** (API `/nsiui/Api/Grid` отвечает 502/пусто).

Проверка VPN на сервере:

```bash
ssh root@201.51.0.171 "bash /opt/emkaro/scripts/n3-vpn.sh status && bash /opt/emkaro/scripts/n3-vpn.sh test"
```
